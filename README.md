# AI Chatbot

## Description
A simple rule-based AI chatbot built using Python.

## Features
- Responds to user greetings
- Answers basic questions
- Easy to customize
- Beginner-friendly

## Technologies Used
- Python

## Installation
pip install -r requirements.txt

## How to Run

```bash
python chatbot.py
```

## Sample Output
```text
Hello! I am your AI Chatbot.
You: Hi
Bot: Hello! How can I help you?
```
